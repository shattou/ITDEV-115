# ITDEV-115: Intermediate Object-Oriented Programming

### Milwaukee Area Technical College · C#

My C# coursework from ITDEV-115 at MATC.

## Activities

**[RectangleCalculator](RectangleCalculator/)**

Calculates rectangle measurements.

**[EmployeePayroll](EmployeePayroll/)**

Calculates employee pay.

**[BMICalculator](BMICalculator/)**

Calculates body mass index from height and weight.

**[MagicPC](MagicPC/)**

Gives a random answer to a question.

**[StudyHoursTracker](StudyHoursTracker/)**

Records study hours and calculates a weekly average.

**[ElectionResults](ElectionResults/)**

Records candidate votes and finds the winner.

**[StudentGrades](StudentGrades/)**

Stores student scores and calculates grades.

**[BankAccounts](BankAccounts/)**

Uses inheritance for checking and savings accounts.

**[NumberAverage](NumberAverage/)**

Calculates the average of three numbers.

**[ExceptionHandling](ExceptionHandling/)**

Handles errors when calculating test-score averages.

**[CustomException](CustomException/)**

Demonstrates a custom division exception.

**[StoreInventory](StoreInventory/)**

Records and displays store inventory.

**[CoffeeShopMenu](CoffeeShopMenu/)**

Builds a coffee-shop order from menu items.

**[TriviaGame](TriviaGame/)**

Loads trivia questions from a file.

**[AddressBook](AddressBook/)**

Displays contact details in a Windows Forms application.
